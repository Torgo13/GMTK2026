# Doomsday DEADline

## Play online
https://torgo13.github.io/GMTK2026/

## Controls
- Left Click/Spacebar
  - Interact
- 1 Key
  - Open menu

## Build Guide
- Open in Unity 6.3.20f1
  - Uses 'Input Manager (Old)'
- Set Build Profile to Web (or a desktop platform)
- (Optional) Replace ORK Framework 3 demo .dll files with retail versions
  - Required to build Web version
  - Also removes watermark and data asset quantity limitations
